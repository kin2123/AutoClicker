# 轻量连点器 Auto Clicker

开源免费的 Windows 鼠标连点工具。单文件、无广告、界面简洁,全局热键一键启停。

## 界面

主窗口只保留高频参数(点击间隔、随机浮动、鼠标按键、双击 / 按住、启动按钮、状态栏),高级功能集中在顶部菜单栏:

| 菜单 | 内容 |
|---|---|
| **文件** | 保存配置、退出 |
| **位置** | 点击位置…(跟随鼠标 / 固定坐标 + 拾取 / 多点循环坐标列表) |
| **设置** | 热键设置…、高级选项…(点击次数 / 倒计时启动 / 按住时长) |
| **帮助** | 使用说明、关于 |

## 功能

- 全局热键启停,**热键可自定义**(设置 → 热键设置,点按钮后按任意键,ESC 取消;默认 F6)
- 点击间隔 1ms ~ 60s 自由调节,支持**随机浮动 ±N%**(避免机械节拍)
- 鼠标左键 / 右键 / 中键,支持**单击 / 双击 / 按住模式**
- 位置模式:跟随当前鼠标 / 固定坐标 / **多点循环**(多个坐标依次点击)
- 可设点击总次数(设置 → 高级选项),到数自动停止
- **倒计时启动**:按热键后延迟 N 秒开始,方便先切到目标窗口
- **配置自动保存**:所有设置(含热键、坐标列表)重启自动恢复
- **系统托盘**:关闭窗口不退出(最小化到托盘),托盘右键可显示 / 启停 / 退出
- **窗口置顶**:勾选后窗口始终显示在最前面,设置自动保存
- **高精度计时**:Windows 定时器精度提升至 1ms + 忙等待校准
- DPI 感知 + 标题栏/任务栏自定义图标

## 下载

Releases 提供两个版本:

| 版本 | 说明 |
|---|---|
| `AutoClicker.exe` | 单文件免安装版,双击即用(启动需解压,约慢 1~2 秒) |
| `AutoClicker-portable.zip` | 文件夹版,启动更快,适合常驻使用 |

## 从源码运行

```bash
pip install pynput pystray pillow
python auto_clicker.py
```

要求:Windows 10/11 + Python 3.9+

## 打包成 exe

```bash
pip install pyinstaller
python make_icon.py          # 生成 app.ico
# 单文件版
pyinstaller --onefile --noconsole --icon app.ico --add-data "app.ico;." --name AutoClicker auto_clicker.py
# 文件夹版(启动更快)
pyinstaller --noconsole --icon app.ico --add-data "app.ico;." --name AutoClicker auto_clicker.py
```

## 使用说明

1. 在主界面设置间隔与按键,按热键(默认 **F6**)开始 / 停止
2. 要点击固定位置或多点轮流点:菜单「位置 → 点击位置…」
3. 想换热键:菜单「设置 → 热键设置…」
4. 要限定次数或延迟启动:菜单「设置 → 高级选项…」
5. 关闭窗口 = 最小化到托盘;彻底退出请用托盘右键「退出」

## 常见问题

- **杀毒软件报毒?** PyInstaller 打包的 exe 被误报很常见,加入白名单即可。介意的话可用文件夹版,或直接用源码运行。
- **标题栏/任务栏图标不对?** 本版已修复:窗口图标与 exe 图标统一为内置 `app.ico`,并设置了 AppUserModelID 避免任务栏显示成 Python 图标。
- **在某些软件/游戏里没反应?** 试试以管理员身份运行。部分游戏设有反作弊机制,请勿使用本工具。
- **热键不生效?** 可能与其它软件热键冲突,换一个热键。
- **点击速度不够快?** Windows 定时器本身有精度限制,本工具已将精度提升到 1ms。
